# Original demonstration artwork

Generated with the **built-in ImageGen tool**, without reference images or official assets. These are fictional products and an original provisional visual direction, not official AnOtter Game packaging. The selected images were inspected and saved into the repository; only format conversion and responsive resizing were applied afterward.

## Saved assets

All paths are relative to the repository root:

- `theme/anotter-demo/assets/images/ronda-demo-1440.webp` and `ronda-demo-720.webp`
- `theme/anotter-demo/assets/images/expansion-demo-1440.webp` and `expansion-demo-720.webp`
- `theme/anotter-demo/assets/images/accesorio-demo-1440.webp` and `accesorio-demo-720.webp`

The large versions are 1440×960; small versions are 720×480. WooCommerce imports the large versions through the native media APIs and generates its own responsive media sizes. All original rendered packaging visibly says DEMO. Existing custom merchant images are preserved by migration.
